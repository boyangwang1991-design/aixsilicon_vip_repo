# AXI VIP 架构文档

## 概述

AIXSILICON AXI VIP 采用 overlay 架构，将上游 TVIP-AXI 代码与本地扩展隔离。

## 架构层次

```
┌─────────────────────────────────────────────────────────────┐
│                    AIXSILICON Layer                          │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐ │
│  │   Adapter   │  │  Checker    │  │  Coverage Extension │ │
│  └─────────────┘  └─────────────┘  └─────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│                    TVIP-AXI Layer                            │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌───────────────┐ │
│  │ Master  │  │  Slave  │  │ Monitor │  │  RAL Adapter  │ │
│  │ Agent   │  │  Agent  │  │         │  │               │ │
│  └─────────┘  └─────────┘  └─────────┘  └───────────────┘ │
├─────────────────────────────────────────────────────────────┤
│                    TUE / TVIP-Common                         │
│  ┌─────────────────────────────────────────────────────┐   │

```

## 组件说明

### Master Agent

- 发起 AXI 读写事务
- 支持可配置延迟和间隙
- 内置序列生成器

### Slave Agent

- 响应 Master 发起的事务
- 支持可配置响应延迟
- 支持错误注入

### Monitor

- 被动监控总线活动
- 收集事务信息
- 支持覆盖率收集

### RAL Adapter

- 将 AXI 事务映射到 UVM RAL
- 支持 predictor 模式

## 设计原则

1. **Overlay 隔离**：上游代码保持只读，本地修改在 aixsilicon/ 目录
2. **可追溯性**：所有来源通过 provenance.yaml 记录
3. **可复现性**：支持固定种子重跑
4. **可扩展性**：通过 adapter 模式支持本地扩展

## 依赖关系

- **tvip-axi**：核心 AXI VIP 实现
- **tue**：UVM 扩展库（Taichi Ishitani）
- **tvip-common**：VIP 通用组件库
